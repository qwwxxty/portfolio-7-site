# Окраєць — сайт пекарні на заквасці

Демо-проєкт для портфоліо: односторінковий сайт вигаданої пекарні «Окраєць» у Сумах.
Назва, меню, ціни, адреса й контакти вигадані.

Написаний на чистому HTML, CSS і JavaScript, без збірки й залежностей, тому працює на GitHub Pages як є.
Верстка mobile-first: спершу телефон, далі брейкпоінти 720 px і 1080 px.

## Розділи

1. **Перший екран.** Заголовок, що з’являється по словах, штамп, що обертається, і «квиток» із тим, що зараз у печі (рахується за київським часом). Кнопки «Подзвонити», Telegram і Instagram.
2. **Біжучий рядок.** Його швидкість і напрям залежать від скролу.
3. **Про нас.** Історія, фото й цифри з лічильниками.
4. **36 годин однієї буханки.** Таймлайн процесу, що заповнюється під час скролу.
5. **Розклад печі.** Табло з перекидними цифрами годинника. Статуси партій («на полиці», «у печі», «наступна») оновлюються наживо.
6. **Меню.** Хліб тижня і вкладки «Хліб», «Випічка», «До чаю», «Кава й напої». Кнопка «+» додає позицію в торбу.
7. **Передзамовлення.** Торба з лічильниками, форма з перевіркою полів і слотами часу. Після відправлення «друкується» чек.
8. **Для закладів.** Оптові поставки.
9. **Хто пече.** Команда.
10. **Кадри з пекарні.** Галерея у вигляді контактного аркуша з плівки.
11. **Відгуки** у вигляді записок.
12. **Часті питання.** Акордеон із плавним розкриттям.
13. **Контакти.** Адреса, години роботи, статус «відчинено / зачинено» і схема проїзду.

На телефоні після першого екрана знизу з’являється панель «Подзвонити / Telegram / Instagram».
Усі анімації вимикаються, якщо в системі ввімкнено «Зменшити рух».

## Структура

```
index.html      розмітка й увесь текст
css/style.css   стилі
js/main.js      інтерактив: меню, табло, вкладки, торба, форма, анімації
img/            сюди класти свої фото
favicon.svg
```

## Як замінити заглушки на фото

Кожна заглушка — це `<figure class="ph">` з підписом, де вказано пропорції й що має бути на фото.
Усередині вже лежить закоментований `<img>`. Покладіть фото в `img/` і розкоментуйте рядок:

```html
<figure class="ph hero__ph" style="--r: 4 / 5">
  <img src="img/hero.jpg" alt="Полиця з ранковим хлібом" width="1200" height="1500">
  <figcaption class="ph__cap">фото 4:5 · полиця з ранковим хлібом</figcaption>
</figure>
```

Фото саме заповнить блок (`object-fit: cover`) і перекриє підпис. Підпис можна видалити.
Схему проїзду в «Контактах» можна замінити на `<iframe>` з Google Maps у блоці `.map`.

## Що змінити під себе

- **Контакти.** Знайдіть і замініть в `index.html`: `+380500000000` / `+380 50 000 00 00`, `t.me/okraiets_sumy`, `instagram.com/okraiets.sumy`.
- **Години й розклад печі.** Константи `OPEN`, `CLOSE`, `BAKE_MIN` на початку `js/main.js`, а партії задані рядками таблиці `data-board` в `index.html` (атрибут `data-t` — час виходу з печі).
- **Форма.** Зараз заявка нікуди не надсилається, відвідувач бачить лише чек. Щоб приймати замовлення, додайте відправлення (Formspree, Google Apps Script або Telegram-бот) у функцію `printReceipt` у `js/main.js`.
- **Кольори й шрифти.** Змінні на початку `css/style.css` (`--ink`, `--paper`, `--tomato`, `--butter`, `--f-d` тощо).

## Запуск

Відкрийте `index.html` у браузері або запустіть локальний сервер:

```bash
python3 -m http.server 8000
```

## Публікація на GitHub Pages

Settings → Pages → Build and deployment → Source: **Deploy from a branch** → оберіть гілку й папку `/ (root)` → Save.
За хвилину-дві сайт з’явиться за адресою `https://<логін>.github.io/portfolio-7-site/`.
